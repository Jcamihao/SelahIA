# Instruções para agentes de IA

1. **Leia `HANDOFF.md` antes de qualquer coisa.** Ele descreve o projeto, as regras que não podem ser quebradas, o estado atual, as dívidas conhecidas e o que não foi verificado.
2. **Ao terminar uma sessão, atualize o `HANDOFF.md`** (pedido do dono do projeto): data e versão, estado atual, dívidas, o que não foi verificado e o histórico.
3. Responda e escreva commits e documentação em português.
4. Antes de dar algo como pronto, rode `npm run build`, `npx jest` e `npm run test:e2e`.
5. Não faça push para outra branch além da designada na sessão, e não abra pull request sem o usuário pedir.
