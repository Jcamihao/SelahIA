# Release Notes - v2.0.0 (Selah IA)

Remoção de dois adapters da plataforma, a pedido do usuário. Major bump por remover superfície de API pública (rotas deixam de existir).

## 💥 Breaking

- **Removido `velo/support`** — adapter de chat de suporte com IA (`VeloSupportAiController`, `VeloSupportAiService`) e o `VeloModule`. `VeloBack` removido de `SELAH_ALLOWED_SOURCE_APPS`.
- **Removido `selah-coder`** — agente de codificação autônoma sobre Ollama (filesystem/shell/git, aprovação humana, snapshot git, `run_tests`, UI própria) e o `SelahCoderModule`. `BASH_TIMEOUT_MS` (usado só por esse adapter) removido do `.env`.

## 🧹 Limpeza

- `app.module.ts` não importa mais `VeloModule` nem `SelahCoderModule`.
- README atualizado: visão rápida, lista de adapters ativos e estrutura de pastas refletem só `lumen/` e `praiseapp/`.

## ✅ Verificação

- `npm run build` (`nest build`) sem erros.
- `npm test -- --runInBand` — suíte completa passando.
