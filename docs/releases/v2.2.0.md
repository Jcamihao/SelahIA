# Release Notes - v2.2.0 (Selah IA)

Gemini vira o provider padrão e o Selah ganha a base de deploy em produção.

## 🔄 Provider de LLM
- **Gemini é o padrão.** `LLM_PROVIDER` vazio ou `gemini` usa Gemini; Ollama só com `LLM_PROVIDER=ollama` explícito. Lógica única em `src/providers/provider-selection.ts`, usada pelo módulo de providers, pelo `/health` e pelos adapters.
- `provider` nas respostas dos adapters (Lumen, PraiseApp) e no `/health` reflete o provider ativo, em vez de `ollama` fixo.
- **Atenção:** quem rodava Ollama sem `LLM_PROVIDER` definido agora precisa setar `LLM_PROVIDER=ollama` (ou configurar `GEMINI_API_KEY`). Sem key, o Gemini responde erro de configuração.

## 🚀 Deploy
- `Dockerfile` multi-stage (node 20 slim, healthcheck em `/health`) e `.dockerignore`.
- `docker-compose.prod.yml` com bind em `127.0.0.1:${SELAH_HOST_PORT:-3020}` e `env_file: .env.production` (agora no `.gitignore`).
- `deploy/nginx/selah.conf` com HTTPS, proxy pra `127.0.0.1:3020`, body de 20MB e timeout de 120s.

## ✅ Verificação
- `npm run build` e `npm test` passando.
