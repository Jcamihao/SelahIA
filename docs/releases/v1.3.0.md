# Release Notes - v1.3.0 (Selah IA)

Esta versão evolui o agente `Selah Coder` (adapter de codificação autônoma sobre Ollama), tornando-o mais seguro, mais transparente e mais capaz de lidar com tarefas longas e multi-etapas sem perder contexto.

## 🚀 Selah Coder Agent

### 🛡️ Segurança e controle
- Gate de aprovação humana antes de executar comandos `run_bash` potencialmente destrutivos (`rm -rf`, `git reset --hard`, `DROP TABLE`, etc.), com expiração automática em 60s.
- Snapshot automático via `git commit` antes de iniciar uma tarefa em repositórios git sujos, permitindo rollback rápido.
- Cancelamento cooperativo de execuções em andamento (stream SSE encerrado pelo cliente interrompe o agente entre iterações).

### 🧠 Contexto e memória mais inteligentes
- Detecção automática de arquivos relevantes para a tarefa via grep de identificadores (`findRelevantFiles`), reduzindo a necessidade do usuário apontar arquivos manualmente.
- Novo arquivo `.selah/instructions.md` para regras imutáveis por projeto, lidas a cada execução junto com `.selah/memory.md`.
- Suporte a continuação de sessão (`messages` no DTO) para retomar o histórico de uma execução anterior sem perder contexto.
- Poda de histórico (`pruneMessages`) para manter conversas longas dentro de um tamanho de contexto controlado.

### 🔧 Novas ferramentas e capacidades do agente
- Nova tool `run_tests`, que detecta automaticamente jest, vitest ou pytest e roda a suíte de testes do projeto.
- Verificação automática de TypeScript (`tsc --noEmit`) após cada `write_file`, retornando erros de tipo direto para o agente corrigir.
- Diff estruturado (linhas adicionadas/removidas) retornado em cada `write_file`, exibido na UI.
- Streaming token a token das respostas do modelo (`stream_token`) para feedback em tempo real na UI.
- Suporte a imagens (`images`) nas mensagens enviadas ao provider Ollama.
- Limite de iterações por execução elevado de 20 para 150, viabilizando tarefas mais longas.

## 🔄 Provider Ollama

- Modelo padrão atualizado de `phi4-mini` para `gemma4:e4b` (`.env.example`, health check, provider e testes).

## ✅ Testes

- `npm run build` e suíte completa (`jest`) validados sem regressões, incluindo os testes do adapter LUMEN.
