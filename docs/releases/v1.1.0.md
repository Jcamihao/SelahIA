# Release Notes - v1.1.0 (Selah IA)

Esta versão marca a primeira grande expansão do ecossistema de adaptadores da Selah IA, trazendo suporte especializado para Louvor, Consolidação e Saúde Ministerial dentro do contexto do PraiseApp.

## 🚀 Novos Adaptadores

### 🎵 Louvor (Worship)
- **WorshipAiAdapter:** Implementação de lógica para sugestão de setlists com restrição estrita de repertório.
- **Notas de Ensaio:** Estruturação de prompt para geração de dinâmicas instrumentais e vocais.

### ⛪ Consolidação
- **ConsolidationAiAdapter:** Análise de sentimento nativa para registros de atividades e gerador de playbooks pastorais.

### 🩺 Saúde Ministerial (Service Reports)
- **Health Analysis:** Novo motor de análise de dados históricos para cálculo de score de saúde e identificação de anomalias de engajamento.

## 🛠️ Núcleo e Performance
- **PraiseAppModule:** Registro centralizado de novos controladores e serviços para os adaptadores mencionados.
- **Provider Gemini:** Melhorias de robustez e suporte a esquemas complexos de saída estruturada.
- **Padronização:** Remoção da dependência externa de Zod em favor de validação nativa por esquemas JSON, garantindo maior performance e menor pegada de dependências.
