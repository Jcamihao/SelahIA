# Release Notes - v2.6.1 (Selah IA)

Correção do adapter **BalancoGordura**: a lista fechada de alimentos voltou a bater com a fonte.

## 🐛 O que mudou
- `meal-photo.food-keys.ts` foi **gerado de novo** a partir de `BalancoGordura/engine/data/food-keys.json` (sha256 `8e0c402d…`). A versão da 2.6.0 vinha de uma fonte anterior (sha256 `704cf9ab…`) e estava defasada.
- **Preparo "assado" passa a ser aceito** para `batata_inglesa` e `batata_doce`. Antes, a foto de uma batata assada era convertida em `outro` (o consumidor pedia as calorias à mão), embora a tabela do app já tivesse esse preparo.
- A lista de 124 alimentos não mudou; só os preparos permitidos desses dois.

## 🧪 Testes
- Suíte total: 169 testes verdes e build limpo, com o arquivo regenerado.
